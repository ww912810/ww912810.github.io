常见问题

我没有服务器，能用吗？

能，这是最常见的用法：装在你家里的 Windows 电脑上就能跑，孩子在本机浏览器里学，同一个 WiFi 下 Pad 打开也能用。不用买服务器，不用付月租。

家里电脑配置要求高吗？

不高：能正常上网的 Windows 10/11 电脑即可，建议内存 8GB 以上。AI 运算在云端模型那边跑，你家电脑只负责打开界面。

云端全包的服务器是谁的？续费多少？

我们替你租好并装好，首年费用含在 ¥1299 里；次年续费约 ¥360/年，我们会提前提醒，你不想续随时停。学习数据在你的专属实例里。

能在 Pad 上用吗？

能。它是网页应用，Pad、手机、电脑都是浏览器打开同一个地址，不用装 App。本地版在家里 WiFi 内使用；云端全包版在任何地方都能打开。

模型 API 是什么？贵吗？

就是让 AI 开口说话的钥匙，向厂商（如 DeepSeek）注册即可拿到。按我们的实测，一轮完整辅导约 ¥0.01，正常学习强度一个月几块钱。费用你直付厂商，我们不经手、不加价。

怎么付款？

微信 / 支付宝：发邮件到 banli@muse.ai 告诉我们你要哪一档，我们发你付款方式；本站在线支付开通后可直接在本站付款。海外用户请切换英文版按 USDT 下单。
